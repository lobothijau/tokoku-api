Tokoku API

API toko online sederhana, dibuat untuk contoh deploy dan CI/CD.

Endpoint

  • GET /health - status aplikasi dan database
  • GET /products - daftar produk
  • GET /products/:id - detail satu produk
  • POST /orders - buat pesanan

Coba sekarang

  • /health
  • /products
  • /products/1

Gambar produk ada di /images/<nama-file>.webp.
